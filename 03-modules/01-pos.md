# Модуль 1. POS на линии раздачи

## Назначение
Касса в конце линии раздачи: принять заказ, рассчитать стоимость, принять оплату, напечатать чек, списать проданные позиции с остатков линии раздачи.

## Пользователи
- Кассир (основной)
- Менеджер (для отмен, возвратов, закрытия смены)

## Основные сценарии
_(заполняет PO)_

1. Гость подошёл с подносом — кассир видит блюда, пробивает их на кассе.
2. Кассир при необходимости пробивает **половину порции** (для блюд, у которых разрешён этот режим). Цена и списание = 50% от полной.
3. Кассир определяет категорию клиента: **обычный гость** (полная цена) или **сотрудник** (применяется скидка — 15% или 40%, см. ниже).
4. Кассир применяет **скидку** на чек или позицию: фиксированные значения — 15% или 40%. Механика применения и права — см. раздел «Скидки».
5. Оплата (нал / карта), чек, списание блюд с линии раздачи.

## Скидки и категории клиентов

**Категории клиентов** (пришло из интервью с PO):
- **Обычный гость** — полная цена.
- **Сотрудник** — пробивается отдельно, применяется скидка (15% или 40% — какая именно и по каким правилам, нужно уточнить у PO).

**Скидки** — два фиксированных процента: **15%** и **40%**. Применяются кассиром. Открытые вопросы:
- Скидка действует на весь чек или на отдельную позицию?
- Кто имеет право применять: кассир самостоятельно, или нужен PIN менеджера?
- Как идентифицируется сотрудник — по списку с ФИО на экране, по пропуску / карте, по устному заявлению, или кассир знает в лицо?

**Техническое решение (предварительно)**: единая таблица `discount_policies` с типами:
- `employee_15`, `employee_40` — для сотрудников (устанавливается выбором категории клиента в чеке),
- `manual_15`, `manual_40` — ручная скидка кассиром.

Каждая примененная скидка фиксируется в чеке с указанием причины и кассира.

## Половина порции
- На уровне блюда есть флаг `allow_half_portion`.
- На кассе если блюдо позволяет — рядом с кнопкой «Добавить» появляется «+ 1/2».
- При пробитии половины: цена × 0.5, количество в чеке = 0.5, списание с линии = 0.5 порции.
- В Z-отчёте и в отчётах менеджера половинки считаются отдельно (для точности foodcost).

## Экраны
- Главный экран кассира: сетка блюд, текущий чек, итог.
- Экран оплаты: выбор способа (нал / карта), ввод суммы, сдача.
- Экран смены: открытие, закрытие, Z-отчёт.

## Бизнес-правила
- Блюдо нельзя пробить, если его остаток на линии раздачи = 0 (или можно? уточнить у PO).
- Отмена позиции — требует права менеджера / PIN?
- Округление итога?
- Весовые блюда — цена × вес, ввод веса с весов или вручную?

## API (чёрные ящики, которые дёргает POS)
- `POST /api/pos/sale` — зафиксировать продажу, получить номер чека.
- `GET /api/line/stock` — текущие остатки на линии раздачи.
- `POST /api/shifts/open`, `POST /api/shifts/close`.

## Интеграции
- Весы (опционально) — уточнить у PO.
- Фискальный регистратор — не в MVP, пока чек в PDF.
- Эквайринг — не в MVP, оплата картой в ручном режиме через отдельный терминал банка.

## Нефункциональные
- Офлайн-режим: при падении сети касса должна продолжать работать, чеки синхронизируются при восстановлении.
- Скорость: выбор блюда → добавление в чек < 200 мс.

## Открытые вопросы для PO
- [x] Скидки — **есть, фиксированные 15% и 40%.** Категория клиента — обычный гость / сотрудник. Детали применения — ниже.
- [x] Комплексные обеды — **нет.**
- [x] Половина порции — **есть для части блюд** (флаг на уровне блюда, цена 50%).
- [ ] **Скидки 15% / 40%**: на весь чек или на позицию? Кто применяет (кассир сам / PIN менеджера)?
- [ ] **Идентификация сотрудника**: по списку ФИО в системе, по карте/QR-пропуску, по устному «я сотрудник», или кассир помнит в лицо?
- [ ] **Весовые блюда**: есть ли блюда, которые продаются по весу (гарнир на раздаче берётся любыми граммами)? Если да — какие весы уже стоят на точке?
- [ ] **Эквайринг**: есть ли у вас терминал для приёма карт? В MVP — оплата картой идёт через отдельный банковский терминал (не интегрированный), кассир просто жмёт «оплачено картой». Ок?
- [ ] **Число кассиров**: один на смену или несколько одновременно?
- [ ] **Печать чека**: обязательна, или можно без печати (номер/QR на экране)?
