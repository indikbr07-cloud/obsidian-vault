# Модуль 3. Номенклатура и ТТК

## Назначение
Справочник всего, что есть в системе: ингредиенты (сырьё), готовые блюда, полуфабрикаты, модификаторы. Технологические карты (ТТК) — рецепты: сколько граммов каждого ингредиента идёт на блюдо, какие потери при обработке, какая расчётная себестоимость.

## Пользователи
- Шеф-повар / технолог (составляет ТТК)
- Менеджер (смотрит себестоимость, правит цены)

## Как устроено сейчас (со слов PO)

**Меню** — сейчас используется R-Keeper. Общий объём меню:

| Категория | Количество позиций |
|---|---|
| Первые блюда | 2–4 |
| Вторые блюда | 20–30 |
| Гарниры | ~10 |
| Салаты | ~12 |
| Напитки (горячая вода, чай, кофе, соки и т.д.) | 20–30 |
| Выпечка | ~10 |
| **ИТОГО** | **~80–95 позиций** |

> Примечание: PO изначально оценил объём в 40–50 блюд, но сумма по категориям даёт ~80–95. Возможно, 40–50 — это «основное ядро», а остальное — напитки и выпечка, которые PO мысленно не считал как «блюда». **Нужно уточнить.**

**ТТК** — уже составлены и ведутся в R-Keeper. Предположительно внутри R-Keeper это Word-документы с таблицами в специальном формате (PO точно не знает структуру). **Нужно выяснить, как R-Keeper хранит ТТК и есть ли экспорт**, чтобы не перенаборять 80+ карт вручную.

**Изменяемость меню** — 80% меню стабильно, 2–5 блюд в день могут заменяться (вероятно, сезонные позиции или замена на основе заявки шефа). **Нужно уточнить механику: это стоп-лист (закончилось), новинки (тест), или сезонные замены.**

**Себестоимость** — рассчитывается через калькуляцию от закупочных цен. PO понимает процесс, уже считает сейчас. **Нужно уточнить метод: последняя цена, средневзвешенная, FIFO.**

## Основные сценарии

1. Шеф заводит новое блюдо «Котлета по-киевски».
2. Прописывает состав: 150 г куриного филе, 30 г масла, 20 г панировки, яйцо 1/2 шт.
3. Указывает процент потерь на обработке.
4. Система считает себестоимость порции на основе текущих закупочных цен ингредиентов.
5. Шеф ставит продажную цену, видит маржу.
6. **Ежедневно**: из общего меню ~80 позиций формируется «меню на сегодня» — убираются блюда в стоп, добавляются сезонные. Кассир и повар видят только актуальные блюда.

## Экраны
- Справочник ингредиентов: название, единица (кг, шт, л), текущая закупочная цена, поставщик по умолчанию, категория.
- Справочник блюд: название, категория, цена продажи, себестоимость, маржа, признак «в основном меню».
- Карточка ТТК: состав блюда, процент потерь, вес нетто/брутто, КБЖУ (опционально).
- Справочник модификаторов (соусы, размеры, добавки).
- **Меню на день**: управление активностью блюд (в стоп / в меню) — ключевой ежедневный экран.

## Бизнес-правила
- Себестоимость пересчитывается при изменении цены ингредиента (метод — после уточнения).
- ТТК версионируется: если поменяли рецепт — старые продажи остаются с расчётом по старой версии.
- Блюдо может быть «составным» — включать не ингредиенты, а другие блюда / полуфабрикаты.
- **Стоп-лист на сегодня**: блюдо в стопе не показывается на кассе и в производственном плане, но остаётся в справочнике.

## API
- CRUD `/api/nomenclature/ingredients`
- CRUD `/api/nomenclature/dishes`
- CRUD `/api/nomenclature/ttk`
- `GET /api/nomenclature/dishes/{id}/cost` — текущая расчётная себестоимость.
- `GET /api/nomenclature/menu?date=...` — меню на конкретный день.
- `POST /api/nomenclature/stop-list` — управление стопами.

## Миграция из R-Keeper
Если R-Keeper предоставляет экспорт (чаще всего — в Excel или XML), пишем импортёр:
- Ингредиенты (номенклатура сырья)
- Блюда (номенклатура готовой продукции)
- ТТК (состав блюд)
- История закупочных цен (если есть)

Альтернатива — ручной перенос. При 80 блюдах и 100–200 ингредиентах — это 1–2 дня работы шефа или оператора.

## Открытые вопросы для PO
- [x] Сколько блюд в меню? — ~80–95 позиций всего, ~40–50 основных блюд.
- [ ] **Уточнить**: 40–50 — это все блюда без напитков и выпечки, или общее число с двойным счётом?
- [ ] **R-Keeper**: какая версия стоит? Есть ли доступ к выгрузке (Excel, XML, база)? Можем ли получить файл выгрузки для анализа?
- [ ] **Сколько ингредиентов** примерно в обороте? (Для сырья — 100 / 200 / 500?)
- [ ] **Метод расчёта себестоимости**: по последней закупочной цене, средневзвешенной или FIFO? Как считаете сейчас в R-Keeper?
- [ ] **Механика «меню на день»**: это стоп-лист (блюдо закончилось), новинки на тест, или сезонные замены по плану?
- [ ] **Полуфабрикаты**: есть ли заранее готовящиеся компоненты (бульон, соус, фарш), которые используются в нескольких блюдах? Как их учитываете сейчас?
- [ ] **Варианты размеров**: есть ли блюда с разными порциями (маленький/большой борщ, стандарт/XL гарнир) или модификаторы (с сыром / без / двойной)?
- [ ] **КБЖУ и аллергены**: нужны на экране гостя / в меню? Обязательны ли по санитарным нормам в вашей точке?
- [ ] **Комплексные обеды**: есть ли «обед по фиксированной цене = первое + второе + салат + напиток»?
- [ ] **Категоризация для кассы**: оставляем те же группы (первые / вторые / гарниры / салаты / напитки / выпечка), или нужно по-другому?
- [ ] **Сезонность цен**: цены на блюда фиксированные круглый год, или меняются (например, летнее меню дешевле)?
