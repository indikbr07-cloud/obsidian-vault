# Модуль 3. Номенклатура и ТТК

## Назначение
Справочник всего, что есть в системе: ингредиенты (сырьё), готовые блюда, полуфабрикаты, модификаторы. Технологические карты (ТТК) — рецепты: сколько граммов каждого ингредиента идёт на блюдо, какие потери при обработке, какая расчётная себестоимость.

## Пользователи
- Шеф-повар / технолог (составляет ТТК)
- Менеджер (смотрит себестоимость, правит цены)

## Основные сценарии
_(заполняет PO)_

1. Шеф заводит новое блюдо «Котлета по-киевски».
2. Прописывает состав: 150 г куриного филе, 30 г масла, 20 г панировки, яйцо 1/2 шт.
3. Указывает процент потерь на обработке (например, 8% от массы курицы уходит в обрезь).
4. Система считает себестоимость порции на основе текущих закупочных цен ингредиентов.
5. Шеф ставит продажную цену, видит маржу.

## Экраны
- Справочник ингредиентов: название, единица (кг, шт, л), текущая закупочная цена, поставщик по умолчанию, категория.
- Справочник блюд: название, категория, цена продажи, себестоимость, маржа.
- Карточка ТТК: состав блюда, процент потерь, вес нетто/брутто, алерген-информация.
- Справочник модификаторов (соусы, размеры, добавки).

## Бизнес-правила
- Себестоимость пересчитывается при изменении цены ингредиента (последняя закупочная / средневзвешенная — уточнить у PO).
- ТТК — версионируется: если поменяли рецепт, старые продажи остаются с расчётом по старой версии.
- Блюдо может быть «составным» — включать не ингредиенты, а другие блюда / полуфабрикаты.

## API
- CRUD `/api/nomenclature/ingredients`
- CRUD `/api/nomenclature/dishes`
- CRUD `/api/nomenclature/ttk`
- `GET /api/nomenclature/dishes/{id}/cost` — текущая расчётная себестоимость.

## Открытые вопросы для PO
- [ ] Сколько блюд в меню? Сколько ингредиентов в обороте?
- [ ] Метод расчёта себестоимости — по последней цене, FIFO или средневзвешенная?
- [ ] Есть ли полуфабрикаты (готовятся заранее, используются в нескольких блюдах)?
- [ ] Нужны ли аллергены и информация для покупателей (КБЖУ, состав)?
- [ ] Категоризация меню для кассы — по какому принципу (первые, вторые, гарниры, напитки)?
