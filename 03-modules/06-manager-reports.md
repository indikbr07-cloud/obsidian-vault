# Модуль 6. Отчёты менеджера

## Назначение
Управленческая аналитика: сколько заработали, на чём теряем, где воруют, что заказывать, кого премировать. Это модуль, ради которого менеджер вообще открывает систему — всё остальное копит данные для него.

## Пользователи
- Менеджер
- Владелец (админ)

## Перечень отчётов

### Финансовые
- **Выручка** — за день / неделю / месяц, с разбивкой по дням, сменам, кассирам, наличный/безналичный.
- **Средний чек** — по периоду, по кассирам, по дням недели.
- **Z-отчёт смены** — выручка смены, количество чеков, нал/безнал, сдача в кассу.

### Меню и продажи
- **Топ и анти-топ блюд** — по выручке и по количеству порций.
- **ABC-анализ блюд** — какие блюда делают 80% выручки.
- **Продажи по часам** — пиковые часы.
- **Не проданные блюда** — то, что есть в меню, но не продавалось Х дней.

### Себестоимость и расхождения
- **Foodcost** — себестоимость / выручка, по блюдам и в целом.
- **Расхождения по нормативу** — сколько сырья должно было списаться по ТТК × продажи, сколько списалось по факту (инвентаризация). **Ключевой отчёт для контроля воровства и перепорций.**
- **Маржа по блюдам** — наценка и прибыль с порции.

### Склад и закупки
- **Остатки по локациям** — сырьё, кухня, раздача.
- **Движение по ингредиенту** — когда пришло, когда списалось.
- **Оборачиваемость** — сколько дней лежит ингредиент.
- **Отчёт закупщика** — сколько выдано налом, сколько потрачено, что куплено, средние цены по рынку.
- **К закупке** — ингредиенты с низким остатком с учётом расхода.

### Персонал
- **Выручка по кассирам** — у кого больше продаж, у кого больше возвратов/отмен.
- **Часы работы** — смены по сотрудникам.

## UI
- Дашборд с ключевыми метриками на главной.
- Раздел «Отчёты» с фильтрами по датам и группировкам.
- Экспорт в Excel / PDF.
