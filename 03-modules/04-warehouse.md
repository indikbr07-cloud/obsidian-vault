# Модуль 4. Склад

## Назначение
Хранение и учёт движения всех товаров — сырья, полуфабрикатов, готовой продукции. Многолокационный: остатки ведутся отдельно по каждой локации. Все движения — документы с подписью ответственного.

## Пользователи
- Кладовщик (приём, инвентаризация)
- Повар (производство → движения кухни)
- Менеджер (просмотр, сверка)

## Локации (минимум)
- `warehouse_raw` — склад сырья.
- `kitchen` — остаток готовой продукции на кухне.
- `line` — остаток готовой продукции на линии раздачи.

## Виды документов
| Документ | Что делает | Откуда запускается |
|---|---|---|
| Приход | Приход сырья на склад | Модуль «Приёмка» |
| Производство | Списывает сырьё со склада по ТТК, приходует готовую продукцию на кухню | Производственный экран |
| Перемещение | Переносит остаток между локациями | Кухня → раздача |
| Продажа | Списывает готовое блюдо с линии раздачи | POS |
| Инвентаризация | Факт vs учёт, корректировка | Кладовщик/менеджер |
| Списание | Порча, бой, просрочка | Кладовщик |

## Бизнес-правила
- Каждое движение имеет дату, ответственного, причину (для списаний).
- Остаток = сумма движений по локации и позиции (партионный или суммовой учёт — уточнить).
- Партионный учёт по датам годности — нужен? (уточнить у PO)
- Инвентаризация создаёт документ корректировки: «по факту 5.2 кг, в учёте 5.5 кг, расхождение 0.3 кг — списание».
- Отрицательные остатки — запрещены или разрешены с алертом?

## API
- CRUD `/api/warehouse/locations`
- CRUD документов: `/api/warehouse/docs/{type}`
- `GET /api/warehouse/stock?location=...` — текущие остатки.
- `GET /api/warehouse/movements?ingredient=...&from=...&to=...` — история.

## Открытые вопросы для PO
- [ ] Нужен ли партионный учёт (отслеживание остатков по датам годности и партиям поставки)?
- [ ] Разрешены ли минусовые остатки (временно, до оприходования)?
- [ ] Сколько локаций в реальности? Есть ли отдельный бар, подсобка, морозилка?
- [ ] Как часто проводится инвентаризация — каждый день (по раздаче), раз в неделю, раз в месяц (по сырью)?
- [ ] Есть ли перемещения между несколькими холодильниками / зонами?
- [ ] Есть ли возвраты поставщикам?
