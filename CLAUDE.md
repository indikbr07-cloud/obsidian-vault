# Директорский журнал — протокол сессий

Этот файл читается автоматически при старте каждой сессии Claude Code. Ниже — правила, которые ты (Claude) обязан соблюдать.

## В начале каждой сессии

1. Определи сегодняшнюю дату.
2. Прочитай последний по дате файл в папке `Директорский журнал/` (не сегодняшний, а предыдущий — где Ибрагим реально работал).
3. Покажи Ибрагиму резюме **в таком формате** и сразу, до любых других действий:

   ```
   Доброе утро, Ибрагим.

   Последняя рабочая сессия — {дата}. Темы, над которыми ты работал:

   1. **{Название темы}**
      Остановились на: {одно предложение}
      Далее планировалось: {одно предложение}

   2. **{Название темы}**
      ...

   С какой темы начнём сегодня? Или новая задача?
   ```

4. Дождись ответа Ибрагима. Не начинай работу, пока он не выберет направление.

## В конце каждой сессии

Когда Ибрагим говорит «заканчиваем», «пока», «на сегодня всё» или аналогичное — **до прощания**:

1. Создай или обнови `Директорский журнал/{YYYY-MM-DD}.md` по сегодняшней дате.
2. Запиши каждую обсуждённую в сессии тему по шаблону (см. ниже).
3. Закоммить изменения одним коммитом с сообщением `journal: {YYYY-MM-DD}`.
4. Запушь в ветку `claude/automation-discussion-08ppN`.
5. Только после этого попрощайся.

## Формат записи журнала

Каждый файл `Директорский журнал/{YYYY-MM-DD}.md`:

```markdown
# {YYYY-MM-DD}

## {Название темы 1}

**Контекст:** 1-2 предложения — о чём шла речь.

**Что обсудили / решили:**
- пункт
- пункт

**Остановились на:** одно предложение — на каком шаге реально закончили.

**Далее:** одно предложение — что логично делать следующим.

---

## {Название темы 2}
...
```

## Правила качества записи

- **«Остановились на»** — это факт, не план. Пиши где реально закончили, а не где хотели бы.
- **«Далее»** — одно действие, не список. Если вариантов несколько — укажи один рекомендованный.
- Если тема закрыта полностью (решение принято, задача выполнена) — пиши «Далее: закрыто».
- Если Ибрагим в течение дня вернулся к теме из прошлых дней — обновляй её запись в сегодняшнем файле, не копируй старую.

## Чего не делать

- Не пересказывай сессию дословно — это не стенограмма.
- Не добавляй темы, которых не было.
- Не пропускай шаг записи журнала, даже если сессия короткая.
