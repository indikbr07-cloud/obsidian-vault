# Obsidian Vault — QSR Canteen Automation

База знаний и разработка системы автоматизации столовой самообслуживания.

Проект развивается в мульти-агентной модели: один агент-архитектор и по одному агенту на каждый модуль. Product Owner — владелец пилотной столовой (Индик).

## Структура

- `00-vision.md` — видение и цель проекта
- `01-scope.md` — операционный поток и 8 модулей системы
- `02-stack.md` — технологический стек и обоснование
- `03-modules/` — детальные ТЗ по каждому модулю
- `04-erd.md` — модель данных (сущности и связи)
- `05-agents.md` — как агенты ведут разработку
- `06-roadmap.md` — план по спринтам и приоритеты
- `code/` — исходный код (появится по мере разработки)

## Текущий статус

Сбор требований. Product Owner рассказывает устройство каждого модуля — архитектор фиксирует в `03-modules/*.md` и задаёт уточнения.
